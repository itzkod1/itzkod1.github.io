常见问题

Firefox 适合我吗？

无论您是注重隐私的普通用户、开发者还是需要多任务处理的办公人员，Firefox 都能提供强大的功能和灵活的定制选项。

Firefox 会比 Chrome 占用更多内存吗？

Firefox 的内存管理经过持续优化。虽然某些扩展程序可能占用较多内存，但 Firefox 本身致力于在性能和资源占用之间取得平衡。

如何安装扩展程序？

点击浏览器右上角的菜单按钮，选择“附加组件”或直接访问 Firefox 扩展商店，即可浏览并安装数千个免费插件。

Firefox 是否支持同步功能？

支持。您可以通过 Firefox 账号同步书签、密码、历史记录和打开的标签页，在所有设备间无缝切换。
